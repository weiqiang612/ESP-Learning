# S7 · 长期稳定与扩展

> 整理日期：2026-11-10  
> 状态：待开展。这份文档记录学习目标，不代表功能已实现或已验证。  
> 定位：实体 AI Agent 桌宠长期学习路线的第七阶段，暂不涉及毕业设计。

完整路线见 [S1～S7 学习路线](S1-S7-学习路线.md)。本文作为 S7 的补充说明。

## 阶段目标

在已有桌宠原型的基础上，完善设备管理、故障恢复、固件更新和能力扩展机制，让它能够长期使用、维护并逐步增加新能力。按实际需要学习 KiCad，设计自己的电路板。

预计投入：2～4 个月。时间仅作参考，以实际交付成果判断进度；本阶段的各项能力可以逐项推进。

## 学习内容

- 设备协议与设备管理。
- 故障恢复与可靠性测试。
- OTA 固件更新。
- 能力扩展机制。
- 固件、协议和硬件的版本管理。
- PCB 设计：按实际体积、接线和可靠性需求决定是否学习和实施。

## 原定交付

**不修改 Agent 核心，就能为它添加一种新的外部硬件能力。**

这里允许新增相应的硬件驱动、设备能力描述、工具或适配代码；目标是让扩展通过明确的接口接入，避免每增加一种外设就重写 Agent 的核心流程。

## 执行约定

1. 根据实际使用中遇到的问题，逐项选择改进内容，不要求同时启动全部工作。
2. 基础异常处理在前面阶段逐步加入；S7 在已有基础上完善长期运行能力。
3. OTA、能力扩展和自制 PCB 分别推进，不必全部完成才算取得阶段成果。
4. 自制 PCB 按需开展。现成开发板满足尺寸和使用需求时，可以继续保留。
5. 每次改进都记录触发问题、修改内容和验证结果，区分计划、实现与验证。

## 开展时再细化的事项

以下内容尚未确定，进入本阶段后依据实际系统补充，不作为当前额外承诺：

- 首个需要扩展的外部硬件能力。
- 长期运行的环境、时长和通过条件。
- 需要验证的故障场景及恢复行为。
- 是否需要 OTA，以及更新失败时的处理方式。
- 是否需要自制 PCB，以及希望解决的具体问题。
