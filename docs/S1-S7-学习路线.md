# 实体 AI Agent 桌宠：S1～S7 学习路线

> 整理日期：2026-11-10  
> 依据：本次对话中确认的七个短期目标。保留原来的阶段顺序、预计投入、学习内容和交付成果。  
> 状态更新于 2026-11-19。S1 进行中，`hello_world` 已通过实板烧录和串口验证，下一步是板载彩灯。  
> 定位：长期学习与个人项目，暂不考虑毕业设计。

## 长期目标

打造一个可爱、可扩展的实体 AI Agent。云端提供智能，本体负责感知、表达和动作，未来能够连接家居设备，并逐渐成为个人智能中控。

## S1 · 控制现实

**预计投入：1～2 周。**

让 ESP32-S3 成功运行自己写的程序，控制 LED 和读取按键。

**学习：**开发环境、烧录、串口、GPIO、基础电路。

**交付：**按一下按钮，灯改变状态。

## S2 · 感知与行动

**预计投入：2～3 周。**

接入距离传感器和舵机，让设备检测到有人靠近时自动转动。

**学习：**传感器通信、PWM、舵机控制、供电。

**交付：**无需电脑干预，设备自动感知并行动。

## S3 · 让桌宠活起来

**预计投入：2～3 周。**

用 OLED 显示眨眼、开心、睡眠等表情，把传感器与表情联动起来。

**学习：**屏幕驱动、动画、定时任务、状态机。

**交付：**一个能自主作出反应的小桌宠原型。

## S4 · 接入云端大脑

**预计投入：3～4 周。**

让 ESP32 主动连接云端服务，Agent 可以改变桌宠的表情、控制动作，也能查询传感器状态。

**学习：**Wi-Fi、WebSocket、JSON 协议、设备鉴权、断线重连。

**交付：**输入「开心地向我打招呼」，机器人执行并反馈结果。

## S5 · 成为家居中控

**预计投入：4～6 周。**

接入 Home Assistant 或已有的智能设备，让 Agent 能查询状态、控制灯光，并完成一个有实际价值的自动化场景。

**学习：**设备接入、工具权限、状态同步、自动化。

**交付：**用桌宠控制一盏真实的智能灯，查询并验证开关状态。

## S6 · 拥有完整身体

**预计投入：4～8 周。**

设计属于自己的桌宠造型，使用 CAD 建模，3D 打印外壳，安装屏幕、控制板、传感器和舵机。

**学习：**FreeCAD、尺寸公差、结构装配、固定与维护。

**交付：**能稳定放在桌上、可以拆装维护的实体机器人。

## S7 · 长期稳定与扩展

**预计投入：2～4 个月。**

完善设备管理、故障恢复、固件更新和能力扩展机制。按实际需要学习 KiCad，设计自己的电路板。

**学习：**设备协议、OTA、可靠性测试、PCB、版本管理。

**交付：**不修改 Agent 核心，就能为它添加一种新的外部硬件能力。

补充说明见 [S7 · 长期稳定与扩展](S7-长期稳定与扩展.md)。

## 三个里程碑

| 里程碑 | 对应阶段 | 达成后的样子 |
|---|---|---|
| 它活起来了 | S1～S3 | 能感知人靠近、改变表情、转动身体；没有 AI 也能独立运行 |
| 它能帮你做事了 | S4～S5 | 能与云端 Agent 交互，并控制真实家居设备 |
| 它成为自己的产品了 | S6～S7 | 拥有独立外形、可靠运行能力和可扩展接口 |

## 已确认的执行约定

1. **保留七阶段顺序。**不要求把联网提前，也不把家居控制移出路线。
2. **只细化眼前阶段。**阶段内部拆成小实验，避免一次调试全部模块。例如 S2 先单独读取距离，再单独控制舵机，最后把两者联动。
3. **时间是预估。**遇到接线、供电或调试问题时，根据实际情况调整，不以超出预计周数判断失败。
4. **基础问题随阶段处理。**例如 S2 处理舵机供电，S4 处理断线重连，S7 再完善长期运行能力。
5. **S7 按需逐项推进。**OTA、能力扩展、自制 PCB 可以分别开展；不要求全部完成才算取得成果。
6. **记录真实进度。**区分计划、实现与验证；完成时记录可复现步骤及结果。

## 当前下一步

### 已完成的学习与准备

- **硬件资料。** 手上的开发板型号为 ESP32-S3 N16R8，已将[核心板原理图](references/core-board/ESP32-S3-N16R8-核心板原理图.pdf)存入项目。
- **原理图第一遍。** 用同名网络标签追踪了 3.3 V 供电、`EN` 复位和 `GPIO0` 启动选择，梳理了 CH340C 与 `DTR`/`RTS` 自动下载电路，以及两个 Type-C 口的数据路径和 `CC1`/`CC2` 的接入检测。已找到 `GPIO48` 到板载 `WS2812B` 彩灯的数据线。
- **本地编译。** 用 ESP-IDF v6.1 为 `esp32s3` 编译了 [`hello_world`](../examples/hello_world/)，已核对 `build/hello_world.bin`、`build/hello_world.elf` 和构建元数据。
- **实板验证（2026-11-19）。** 板上右侧 `UART` 口通过 CH340C 接到 Windows，安装驱动后识别为 `USB-SERIAL CH340 (COM5)`。在 `examples/hello_world/build` 中用 ESP-IDF 的 Python 环境运行 `python -m esptool --chip esp32s3 --port COM5 --baud 115200 --before default-reset --after hard-reset write-flash @flash_args`，三个镜像均通过写入校验。随后用 pySerial 从 `COM5`（115200 波特）收到 `Hello world!`，确认程序已在板上运行。日志检测到 16 MB Flash，示例固件配置使用 2 MB。
- **独立上板练习（2026-11-19）。** 在 VS Code 中把 `app_main()` 的问候语改成 `Hello from my ESP32!`，通过 `UART`（`COM5`）构建、烧录并监视，在终端看到更新后的文本。已亲手完成从修改源码到实板验证的流程。
